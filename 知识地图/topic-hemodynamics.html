血流动力学治疗的三个核心属性

目标导向性
每个参数都有目标值。治疗是目标值变化的过程。没有哪个参数能解释全貌，但目标值有固定特定意义。
连续动态性
不同时间点的治疗方向、程度、目标可以不同。休克治疗从"维持血压"到"灌注导向"是进步。
整体协调性

个体化治疗
从整体目标出发，在可操作位点定量调控。不同患者同一参数意义不同，需个体化滴定。
— 02 / SEVEN

心脏泵功能

STARLING · SYSTOLIC · DIASTOLIC
STARLING

Starling 定律：前负荷决定每搏做功

核心表述
心肌收缩产生的能量是心肌纤维初长度的函数。舒张末容积越大 → 收缩做功越多 → SV 越多。
曲线特征
陡峭段：P↑ → SV 明显↑（容量有储备）
平台段：P↑ → SV 不再↑（容量无储备）
正常时不出现下降支。
收缩力改变
收缩力↓ → 曲线右移（同前负荷做功↓）
收缩力↑ → 曲线左移（同前负荷做功↑）
生理意义
回心血量↑ → 前负荷↑ → CO↑ → 回心血量=CO 平衡。精细调节心输出量。
收缩

心室收缩功能

异长自身调节
基于 Starling 定律：初长度改变 → 收缩力改变。前负荷依赖。
等长自身调节
与初长度无关的收缩力本身改变。受自主神经、体液因素影响。
临床监测：SV、SWI、EF、dP/dt max 等动态指标。活体几乎不可能去除前/后负荷影响，只能动态观察趋势。
收缩力↓ 常见原因：急性心梗、低氧、严重感染、酸中毒、心肌抑制药物。
舒张

心室舒张功能（顺应性）

概念公式意义
顺应性ΔV/ΔP单位压力改变导致的容量改变。顺应性↑ = 心室更"软"。
硬度ΔP/ΔV顺应性的倒数。硬度↑ = 曲线左移，少量输液即致压力骤升。
关键：同一心室，容量越大 → 顺应性越小。小容量时输液 Δa → Δc（压力小变）；大容量时同样 Δa → Δb（压力大变）。
顺应性↓ 原因：容量逐渐增加、心肌缺血、心脏压塞、PEEP、休克、儿茶酚胺。
顺应性↑ 原因：心肌灌注改善、硝酸甘油/硝普钠/钙通道阻滞剂。

容量

张力容量 vs 非张力容量

类型占比作用
非张力容量70~75%维持血管形状，不产生管腔内压力
张力容量25~30%牵拉血管壁产生张力 → 形成 MCFP
气球比喻：维持形状的气体 = 非张力容量；继续吹大 → 气球壁受牵拉产生压力 = 张力容量。
只有张力容量决定 MCFP。血管收缩药使非张力→张力容量（MCFP↑）；血管扩张则相反。
大出血代偿：机体使非张力→张力容量，维持 MCFP 和回心血量。代偿耗尽后血压骤降。
压力

CVP 与 PAWP 的临床价值与局限

CVP 反映右心前负荷
中心静脉与右房几乎无阻力 → 近似直接测量。同时受心功能曲线和静脉回流曲线影响。
CVP 的局限
基础 CVP 不能预测容量反应性。CVP 在 0~20 mmHg 之间均有无反应者。
PAWP 反映左心前负荷
气囊嵌顿后测左房压。左右心顺应性不同，急性左心衰时 PAWP 比 CVP 更敏感。
PAWP 的局限
不是直接测量 LAP；受胸腔内压、二尖瓣病变等影响。同样不能预测容量反应性。
共识：CVP 8~12 mmHg、PAWP 12~15 mmHg 仅为专家推荐，非金标准。CVP/PAWP 作为容量复苏安全性指标而非反应性预测指标。

— 05 / SEVEN

后负荷与心室-动脉偶联

SVR · EA/EES
射血

心室射血过程：动脉弹性储器效应

收缩期
心室压↑ → 主动脉瓣开放 → SV 快速射入大动脉。动脉壁扩张，储存部分 SV。
瓣膜关闭
心室内压↓ 至 = 动脉压 → 主动脉瓣关闭 → 收缩期结束。剩余 40~50 ml 为正常收缩末容积（ESV）。
动脉弹性储器效应：收缩期扩张储能 → 舒张期弹性回缩继续推动血流 → 维持舒张压 + 保证组织灌注连续性。
临床意义：老年/高血压/动脉硬化 → 储器效应↓ → 收缩压↑、舒张压↓、脉压↑ → 后负荷↑ → 心室做功↑、冠脉灌注↓。这是高血压靶器官损害的核心机制。
后负荷

SVR：左心室后负荷的主要指标

公式参数意义
SVR = 80 × (MAP − RAP) / COMAP = 平均动脉压
RAP = 右房压
CO = 心输出量		后负荷↑ → CO↓（负相关）
后负荷↓ → SV↑ + 耗氧↓
SVR 的局限：建立在恒流、均质假设上，忽略了波动性。大动脉是弹性器官，心脏射血是搏动性的。不同病理状态和药物干预下可能高估或低估。
SVR↑ 不一定需要血管扩张药：容量不足时 SVR 可因 CO↓ 而计算值升高，补液后自然下降。
偶联

心室-动脉偶联（Ea/Ees）

Ees（心室收缩末弹性）
<
心肌收缩能力指标。收缩力↑ → Ees↑ → 曲线左移。
Ea（有效动脉弹性）
后负荷综合指标。后负荷↑ → Ea↑ → 曲线右移。

临床应用

容量反应性评估

FLUID RESPONSIVENESS
状态

容量状态评估 ≠ 容量反应性

压力指标
CVP（中心静脉压）、PAWP（肺动脉嵌顿压）。床旁易得，但预测反应性差。
容积指标
GEDV（全心舒张末容积）、ITBV（胸腔内血容积）、LVEDA（左室舒张末面积）。需 PiCCO/超声。
关键区分：容量状态是「现在有多少」（静态），容量反应性是「加一点会怎样」（动态）。
研究证据：CVP/PAWP 与 EDV/SV 无相关性，变化也无密切相关。CVP/PAWP 8~12 / 12~15 mmHg 仅为专家推荐复苏目标。

关键区分：容量反应性 ≠ 容量不足。存在容量反应性说明有前负荷储备，不代表一定需要补液。
盲目扩容：仅 40~72% 的扩容治疗有反应。ARDS 限制性液体管理氧合改善、ICU 住院时间缩短。
方法

三种评估方法对比

方法原理优点局限
PPV/SVV心肺相互作用：呼吸变异 → SV 变异连续、实时、无创需机械通气 + 窦律 + Vt≥8；心律失常/自主呼吸失效

PLRT 阳性标准：主动脉流速 ↑ ≥ 10%~13%（敏感性和特异性均 > 80%，21 章 338 行）。效果维持 ~10 min，多在 1~2 min 内出现 CO 改变。
容量负荷试验 5 要素：① 液体种类 ② 用量 ③ 时间 ④ 预期效应 ⑤ 患者特点。

ABC

血流动力学 ABC 理论

A — 心脏前负荷
容量状态 + 容量反应性。调整 CVP/PAWP 到最佳点。CVP 不等于容积，但仍有安全边界意义。
B — 心脏泵功能
心肌收缩力。CO/SV/SWI 反映泵功能。正性肌力药（多巴酚丁胺/米力农）提升泵功能。
C — 后负荷
SVR。血管扩张药降低后负荷 → CO↑。但需维持灌注压（MAP ≥ 65 mmHg）。
整合
三个变量相互依赖。调节一个必须考虑对另外两个的影响。目标：整体最佳化而非单一参数正常化。
PV

左心室压力-容积环（P-V Loop）：综合心功能的最直观工具

阶段瓣膜心室内变化
A → B（充盈）二尖瓣开心室被血液充盈，压力略升。AB 段斜率反映顺应性。
B → C（等容收缩）二尖瓣关→主动脉瓣未开压力急升，容积不变。
C → D（射血）主动脉瓣开心室继续收缩，血液射入动脉。
D → A（等容舒张）主动脉瓣关压力急降，容积不变。剩余 40~50 ml 为 ESV。
关键点位：B 点横坐标 = 舒张末容积（EDV）；D 点横坐标 = 收缩末容积（ESV）；BC 与 AD 间距 = 每搏量（SV）。
心功能改变 → 环位移：收缩力↓ → SV↓、ESV↑（环内缩）；前负荷↑、后负荷不变 → SV↑（环右移但更宽）；后负荷↑ → EDV 代偿性↑（整个环右移）。
双心室

左、右心室的不同特点：双心室处理策略的解剖基础

右心室特点
心肌薄、顺应性高、容量大但压力低。RV 衰时需维持前负荷（避免利尿/扩血管）。
室间隔互动
RV 扩张 → 室间隔左移 → 挤压 LV → LV 顺应性↓ → 即使 RV 容量↑，LV CO 也可能下降。
左心室特点
心肌厚、压力高、对后负荷敏感。LV 衰时减少前负荷 + 增强收缩力为主。
双心室失代偿
双侧衰竭时容量-压力变化趋于平行，肺水肿风险低于单纯 LV 衰。扩容难使 CO↑。
临床要点：输液量过大 → 双心室负荷共同↑ → 肺水肿风险。LV 衰时 RV 压力略增即可致 LAP 显著↑（超过胶体渗透压 ~24 mmHg）→ 严重肺水肿。
参数

其他常用参数：心肌收缩力监测的具体指标

指标反映优势 / 局限
EF（射血分数）SV / EDV弱化前负荷影响，但受后负荷影响明显
SWI（每搏做功指数）心室射血实际做功综合前/后负荷信息，较 SV 更相关。儿茶酚胺可使 SWI 升高（等长调节）。
心室收缩末斜率（Ees）不同前负荷下收缩末点连线斜率与收缩力正相关，受前负荷影响极小，最直接反映收缩力
超声（EF / FS / 室壁运动）整体或节段收缩功能直观、可床旁，三维成像与自动边界技术拓展应用

氧输送及其相关问题

DO₂ · VO₂ · SvO₂
DO₂

氧输送 (DO₂)：左心向全身输送的氧总量

公式参数正常值
DO₂ = CO × CaO₂ × 10CO = 心输出量
CaO₂ = 动脉血氧含量
(主要取决于 SaO₂ + Hb)		500~700 ml/(min·m²)
(静息态)
氧的存在形式
① 血红蛋白结合（主要运输方式，每 g Hb 结合 1.34 ml O₂）
② 物理溶解（少量，0.022 ml/100ml/100mmHg）
系统依赖
呼吸系统（SaO₂）+ 血液系统（Hb）+ 循环系统（CO）三者共同决定。
氧的储存特性：组织不能储存氧 → 每一刻都需要供给 → 纠正组织缺氧=支持治疗主要目标。
临床意义：DO₂ 从"诊断指标"演变为"连续动态监测指标"——是休克复苏的核心目标之一。
VO₂

氧耗量 (VO₂) 与氧摄取率 (O₂ext)

公式正常值意义
VO₂ = CO × (CaO₂ − CvO₂) × 10120~160 ml/(min·m²)组织实际消耗的氧量。VO₂ < 氧需量 = 组织缺氧
O₂ext = (CaO₂ − CvO₂) / CaO₂22%~30%反映组织摄取氧的能力
关键区分：VO₂（实际耗氧量）≠ 氧需量（组织代谢需要）。VO₂ 受组织氧摄取能力影响。
升高 VO₂ 的路径：① 提升 DO₂（治标） ② 改善组织氧利用（治本） ③ 降低不必要氧耗（镇静/控温）。
SvO₂

静脉血氧饱和度：组织水平缺氧的窗口

SvO₂（混合静脉血）
来自肺动脉，反映全身组织平均氧剩。正常 65%~75%。
ScvO₂（中心静脉）
来自上腔静脉，仅反映上半身体。临床更易获得。
SvO₂ ↓ 的意义
动脉氧供不足 或 组织摄取↑ → 强烈提示组织缺氧。
SvO₂ ↑ 的意义
外周血管扩张/分流（如感染性休克、肝硬化）。单纯提高 DO₂ 不足以纠正组织缺氧。
复苏里程碑：Rivers EGDT 试验把 ScvO₂ ≥ 70% 作为感染性休克早期复苏终点，显著降低死亡率。这是氧代谢导向治疗的经典证据。

不同休克类型的临界值偏移：
· 低容量/心源性/梗阻性休克：DO₂ 明显 ↓，组织摄氧代偿

PO₂ gap

为什么大循环正常不等于组织不缺氧

临床困惑
部分感染性休克患者：CVP/MAP/CO/DO₂/ScvO₂ 已达目标，乳酸酸中毒、MODS 仍持续进展。
心功能悖论
40%~50% 感染性休克有 EF↓，但冠脉造影正常、冠脉血流正常、活检无坏死，且完全可逆。
PO₂ gap（氧分压间隙）
微循环内 PO₂ < 静脉血 PO₂ → 代表分流的严重程度。全身 DO₂ 指标会掩盖微循环障碍。
微循环异质性
Boerma 等用 OPS 观察到感染性休克患者毛细血管开放数量显著减少、灌注异质性（部分低灌、部分正常甚至超常）。
关键启示：全身氧输送指标不能准确反映微循环功能障碍——解释了为什么"宏观达标"但组织缺氧仍进展。
展望

微循环与线粒体：休克治疗的"细胞"层

线粒体功能障碍
休克时细胞利用氧障碍——即使 DO₂ 正常，细胞内仍缺氧。
现有监测工具
舌下 CO₂ 张力、经皮 PO₂/PCO₂、组织氧电极、NIRS、OPS/SDF 暗场成像、微透析仪。
治疗探索
血管扩张剂（硝酸甘油、硝普钠、莨菪碱、己酮可可碱）改善微循环。Ince 报告 OPS 改善但未降低病死率。
现实
目前无普遍接受的改善微循环的方案/药物，仍处于临床研究阶段。
