游离钙和总钙——ICU里的"银行资产"骗局

总钙=银行库存数字，离子钙=钱包现金；五个陷阱(低白蛋白/酸中毒/输血/胰腺炎/CRRT)；临床铁律：怀疑钙代谢异常时直接查离子钙

来源:https://www.douyin.com/video/7620737510691360046
时长:7分34秒
处理时间:2026年05月31日

核心比喻

总钙 = 银行库存数字，只是账面数字，受白蛋白影响大。\ 离子钙（游离钙）= 钱包里的现金，是唯一有生物活性的钙，真正在干活。

就算银行有几百万，出门没现金连瓶水都买不了。\
身体同理：总钙正常，离子钙可能早已见底。

离子钙的生理地位

  • 正常范围：1.1~1.3 mmol/L（极窄）
  • 调节神经传导、肌肉收缩、心脏跳动
  • 稍微波动就可能出大事

五个临床陷阱

陷阱一：低白蛋白血症（最常见）

  • 40%~45%的钙与白蛋白结合（像"定期存款"，动不了）
  • 低白蛋白 → 总钙数字低，但离子钙可能正常
  • 大量输液后：总钙看着还行，离子钙已被稀释到危险水平

陷阱二：酸中毒的假象

  • 酸中毒时，氢离子与钙竞争白蛋白上的结合位点
  • 钙被"挤下来" → 离子钙假性升高
  • 纠酸后：钙重新与白蛋白结合 → 离子钙骤降 → 低钙风暴（抽搐、精神错乱、心律失常）

陷阱三：大量输血（柠檬酸偷钙）

  • 库存血中的柠檬酸像贪婪的水蛭，牢牢吸住离子钙使其失活
  • 被螯合的钙仍计入总钙 → 总钙报告"正常"，实际可用钙已极低

陷阱四：重症胰腺炎

  • 脂肪分解 → 脂肪酸 + 钙 → 皂化（形成"钙肥皂"）
  • 钙被病理过程主动"吃掉"，补进去的钙不断被消耗

陷阱五：枸橼酸抗凝的CRRT

  • 双重打击：
  1. 枸橼酸直接螯合离子钙
  2. 代谢性碱中毒 → 增强白蛋白与钙的结合 → 剩余的离子钙也被绑起来
  • 只看总钙完全无意义，必须勤查离子钙

三步避坑法

  1. 永远优先直接查离子钙（怀疑钙代谢异常时）
  2. 脑中装警报器：记住五个高风险场景
  • 低白蛋白 / 酸中毒 / 大量输血 / 重症胰腺炎 / 枸橼酸CRRT
  1. 对因下药：急症果断处理，慢性问题找到根本原因

四种组合模式总结

总钙离子钙首先考虑
正常低低白蛋白 / 大量输血
正常高酸中毒
低正常低白蛋白（假性低钙）
高低假性升高（酸中毒纠酸后）

临床铁律

怀疑钙代谢异常时，直接查离子钙，不要只盯着总钙。
